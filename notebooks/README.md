# 학습 노트

`foundations/Phase2.ipynb`는 기존 Python 기초 노트북을 내용 변경 없이 이동한 파일입니다. 출력과 오류 기록을 포함합니다. 원본의 `print(vh([110:]))` 셀에는 문법 오류가 있고, CDR 문자열 슬라이싱은 연습용이므로 정식 항체 numbering 결과로 사용하지 않습니다. 예시 pLDDT·RMSD 값은 실제 모델 실행 결과가 아닙니다.

학습·탐색은 노트북에서 진행하고, 재사용할 함수는 해당 기능 폴더로 옮깁니다. 앞으로 추가하는 데이터 경로는 저장소 루트의 `data/`를 기준으로 하며 노트북의 현재 작업 디렉터리를 먼저 확인합니다.
