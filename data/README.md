# 데이터 출처와 관리

## 보존한 데이터

- 파일: `raw/1N8Z.pdb`
- 출처 확인: https://www.rcsb.org/structure/1N8Z
- 재다운로드 URL: https://files.rcsb.org/download/1N8Z.pdb
- 이전 위치: `phase2-python/data/1N8Z.pdb`
- 기존 파일을 바이트 변경 없이 이동했습니다. 원래 다운로드 날짜·수정 여부는 확인되지 않았습니다.

## 다음 수업 데이터

`5X8M`은 아직 다운로드하지 않았습니다. 사용할 때 RCSB에서 구조와 chain 정보를 확인하고 출처를 추가합니다. 서로 다른 PDB의 chain 역할을 그대로 재사용하지 않습니다.

## 관리 규칙

`raw/`에는 원본, `processed/`에는 가공 데이터를 둡니다. 기존 1N8Z 파일만 Git에 보존하며 추가 원본·가공 데이터는 기본적으로 제외합니다. 새 데이터는 출처 URL, 취득 날짜, 사용 조건, 재현 명령을 여기에 기록합니다. 작은 검증용 데이터만 검토 후 명시적으로 추가합니다.
