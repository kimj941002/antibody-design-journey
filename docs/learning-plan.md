# 프로젝트 우선 학습 계획

주 20시간 이상, Python 함수까지 학습한 상태를 기준으로 합니다. 아래는 목표이며 완료 이력이 아닙니다. 진행하면서 실제 결과와 걸린 시간을 기록합니다.

| 단계 | 직접 만들 결과물 | 필요한 개념 |
| --- | --- | --- |
| 1. 구조 읽기 | chain·잔기 수 분석 | 함수, 반복문, 객체, Biopython |
| 2. 구조 분석 | 거리·접촉 잔기 분석 | NumPy, 좌표, 필터링 |
| 3. 서열 설계 | ProteinMPNN 실행·결과 수집 | CLI, 환경 분리, 모델 추론 |
| 4. 후보 분류 | 기준 모델과 PyTorch 학습 비교 | 데이터 분할, loss, optimizer |
| 5. 설계 통합 | RFantibody 소규모 파이프라인 | GPU, 로깅, 예외 처리 |
| 6. 평가·보고 | 실험 비교와 재현 방법 | 구조 정렬, 지표, 테스트 |

첫 구현은 `structure_analysis/`에 작성합니다. 직접 이해하고 설명할 수 있는 작은 기능부터 추가합니다. 공개 실험 라벨을 사용할 때 중복·유사 서열과 표적에 따른 데이터 누출을 검토합니다. 구조 점수나 모델 신뢰도를 실제 결합력의 측정값으로 취급하지 않습니다.
